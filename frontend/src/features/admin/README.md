# Super admin

The `SUPER_ADMIN` workspace is routed from `src/app` and organized as follows:

- `api` - admin API functions
- `components` - shared navigation, page headers, tables, modals, and status UI
- `hooks` - shared loading and error state
- `pages` - overview, business management, plans and subscriptions, categories, users, and reports
- `admin.css` - admin workspace layout and responsive styles
